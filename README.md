# MULTIcore Resources

**MULTIcore was founded and created by RINGO (RINGOscripting).**

Extra scripts for a **MULTIcore** server. The base server (core, character, inventory, clothing, stores, HUD, jobs, houses and more, with the txAdmin recipe) is at https://github.com/MULTIcore-RedM/MULTIcore-Server. Install that first.

Everything here is optional: pick the scripts you want.

## Installing a script
1. Copy its folder from `resources/[multicore-addons]` into your server's `resources` folder.
2. Add `ensure <ScriptName>` to `server.cfg`, **below** the MULTI scripts of the base server.
3. Restart the server. Each script makes its own database tables on the first start. Its README lists anything else it needs.

## Scripts
| Script | What it does |

| [MULTIbelt](resources/%5Bmulticore-addons%5D/MULTIbelt) | Carried tools (lantern, lasso, machete, metal detector, arrows) show on the belt and back while they are not in your hand. |
